# Song Fei

Personal site based on [DevPortfolio](https://github.com/RyanFitzgerald/devportfolio).

```sh
npm ci
npm run dev
```

Edit the profile and experience in `src/config.ts`. Run `npm run build` to generate the static site.

Choose GitHub Actions as the publishing source under **Settings → Pages**. Pushes to `master` deploy automatically. You can also run **Deploy to GitHub Pages** manually from the Actions tab.
