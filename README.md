# Song Fei

Personal site based on [DevPortfolio](https://github.com/RyanFitzgerald/devportfolio).

```sh
npm ci
npm run dev
```

Edit the profile and experience in `src/config.ts`. Run `npm run build` to generate the static site.

To publish, choose GitHub Actions as the source under the repository's **Settings → Pages**, then run the **Deploy to GitHub Pages** workflow.
